# Arana Space — Brand Assets

Brand direction: warm, welcoming, contemporary coffee & eatery.

## Identity
- Brand: Arana Space
- Tagline: Good Food, Good Mood.
- Primary: espresso brown (#4B2818 / #512B18)
- Secondary: caramel (#B87943 / #C58B55)
- Background: warm cream (#F8EDDD / #F3DFC5)
- Highlight: latte beige (#F5DFC3)

## Files
- `public/images/arana-space-logo.svg` — primary horizontal logo
- `public/images/arana-space-icon.svg` — app icon / favicon
- `public/images/arana-space-hero.svg` — homepage hero artwork
- `public/images/arana-space-promo.svg` — promotion banner artwork

## Integration
The public layout uses the logo and icon; the homepage uses the hero and promo artwork. All files are scalable SVG assets and can be edited in Figma or a vector editor.

## Notes
The SVG illustrations are original brand graphics. Replace or supplement menu artwork with licensed, real product photography as the menu catalog is finalized.
